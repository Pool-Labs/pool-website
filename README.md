# Pool website

The built files of Pool's marketing website, deployed by Vercel. The source and the design work live in the private `pool-labs/pool_app` repo; only finished site files are copied here.

Pages:
- `/`: the real site (built from `pool_app` branch `claude/site-real`, folder `site/`): the locked hero, type and M2, the menu and the waitlist (Loops).
- `/m2`: the M2 design page from the board, as it was live on 16 to 17 Nov.
- `/before`: the page before the iPhone wall and liquid fixes.

Pre-launch: every page is marked `noindex`, and `robots.txt` blocks search engines.
